## DSH 运行时适配（PRDCraft 注入）

> 本节由 PRDCraft 打包时注入,用于把原版技能映射到 DSH 运行环境;正文其余部分保持原版。

### 与其他技能的分工

- **默认入口是 `prd-craft`**:未点名技能的常规「写 PRD / 需求文档 / 梳理需求」请求由 `prd-craft` 承接(深度访谈 → 拆解 → PRD → 评审 → 门禁的完整两阶段流程)。
- **本技能的定位**:① 用户点名 `prd-generator`;② UML 用例建模 / 用例规格说明 / 数据字典驱动的 PRD;③ 简单功能、紧急需求的快速一次性成文(对齐上游 prd-workflow 的导流规则)。深度访谈、评审、版本迭代请走 `prd-craft` / `prd-workflow`。
- 已有完整文档的润色、代码生成、技术架构设计不在本技能范围(原版边界,继续有效)。

### 工作区约定

- 产物与其他技能共享 `prd-workspace/<项目名>/` 目录:PRD 写入 `prd-workspace/<项目名>/PRD-uml.md`,数据字典、用例规格等长文可另存同目录子文件。
- 会话 agent 直接按本技能正文工作流执行,无需外部脚本或运行时。
